How it works Agents Guarantees GitHub

Hand off the code. Keep the judgment.

Switchboard lets the coding agent you already work with hand a task to any of 18 CLI coding agents: Claude Code, Codex, Cursor, Aider and more. It gets back a structured report and the diff. Your agent reviews the work, re-runs your tests, and lands it. Nothing commits without that review.

How it connects

Four steps, one connection

Your agent stays the orchestrator. The implementer does the typing. Switchboard connects the two and records every outcome.

1
Your agent

Brief

Writes a self-contained task spec. The implementer has none of your chat history, so the brief carries the context.

2
Switchboard

Dispatch

One command launches the implementer, watches it, and writes result.json on every outcome.

3
Your agent

Review

Reads the implementer's report and the touched files, then re-runs your test, lint and build commands.

4
Your agent

Land

Commits the verified work itself. Switchboard never commits, so every change that lands has been through your review.

House rules

The same guarantees for every agent

All 18 relays run on one shared engine, so a fix or a safeguard lands for every agent at once.

A result on every outcome

Once the brief is accepted, result.json is written atomically whether the run completes, fails, times out, stalls, or is killed. A missing CLI exits 127, and a broken one is never sent the brief.

completed failed timeout stalled aborted *_unavailable

No runaway processes

The watchdog stops the whole process tree, grandchildren included. An opt-in stall watchdog stops an agent that has gone silent long before the timeout.

Read-only you can check

On 15 of the agents, a read-only run fingerprints the Git working tree before and after. The verdict is true, false, or null when coverage was incomplete. It never reports a clean result it didn't earn.

Many tasks at once

Hand a batch of briefs to several agents in parallel. Each task gets its own git worktree, a missing CLI falls back to your next lane, and one report collects every result, token count and cost.

Private and inspectable

Run folders are private by default. Each relay is one readable Node file with no dependencies, no telemetry, and no network calls of its own.

Lanes

Put each agent in its lane

A lane binds a kind of work to an implementer and its settings. Send reviews to one CLI, bulk refactors to another, and read-only questions to a third. Explicit flags always override a lane.

  • The setup skill finds the CLIs you have installed and proposes lanes.
  • It writes nothing until you approve.
  • A project can override your global lanes.
~/.config/switchboard/config.jsondelegate-fleet.v1
{
  "version": "delegate-fleet.v1",
  "lanes": {
    "review":   { "implementer": "claude", "readOnly": true },
    "refactor": { "implementer": "codex",  "effort": "high" },
    "bulk":     { "implementer": "kimi",   "timeout": "45m" }
  }
}
